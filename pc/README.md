# GlassPlayer PC 1.0.7

> 本目录是 **GlassPlayer 桌面版（Windows）**，位于仓库的 `pc/` 下，与根目录的 Android 版共用同一套接口与产品设计，但实现完全独立（Electron + React + TypeScript），两者可以同时存在、互不影响。
>
> 安装包见 [Releases](https://github.com/624375623/GlassPlayer/releases)，取 `GlassPlayer-Setup-*.exe` 或 `GlassPlayer-Portable-*.exe`。

基于手机版 **GlassPlayer 3.9.40（Android / Kotlin）** 的接口与功能，用 Electron + React 重写的 Windows 桌面播放器。
界面沿用手机版的「液态玻璃」风格，功能覆盖：夸克网盘扫码登录、网盘视频在线播放、五个公开资源站搜索、分享预览与一键转存、B 站弹幕、字幕、断点续播、收藏与播放记录。

## 三、技术要点（为什么 PC 版需要额外一层）

手机端 ExoPlayer 可以直接给播放器注入 Cookie / Referer / UA，浏览器内核不行，所以主进程里加了一个**本地 HTTP 媒体代理**：

```
<m3u8 直链>  ──┐
               ├─ 主进程代理（127.0.0.1:随机端口，带随机 secret）
<m3u8 分片>  ──┘   ├─ 注入 Cookie / Referer / 客户端 UA（解决 CDN 412）
                   ├─ 透传 Range（拖动进度条）
                   ├─ 8 路并行分片拉流（对齐手机版 QuarkParallelDataSource）
                   └─ 重写 m3u8 内的分片 / 密钥地址（解决 CORS）
```

**为什么要并行拉流**：夸克下载直链的单连接被压到 ~100KB/s，浏览器单线程转发大文件根本缓冲不过来。
PC 版先探一次 `206` 拿总长度，再按 512KB 切片、8 条连接并发 Range，写侧严格按序交付（最多预取 16 片 / 8MB）。
本机限速源实测：128KB/s（单连接）→ 1070KB/s（代理），8.4 倍，字节完全一致。

- 所有接口调用都在主进程完成，渲染层拿不到 Cookie，也没有跨域问题；
- 资源站请求走 Electron 网络栈（Chromium），自动跟随系统代理 / 加速器，海外站点才连得上；
- 弹幕颜色按 B 站规范取 `p` 属性第 4 位（手机版误取了字号，会渲染成近黑色，这里已修正）；
- 腾讯弹幕链路与手机版一致（封面 → 整季 vid → 30 秒分段弹幕），差异是搜索改用 360 站内检索（手机版依赖必应 RSS，国内常被重定向且不遵守 `site:`），并按文件名集号直取单集，避免拉整季 200 集元信息。

### 弹幕为什么不会配到预告片

B 站的预告片和正片**共用同一个集号**：`episodes` 里《凡人修仙传》154~201 集各多出一条 `badge="预告"` 的重复条目，《三体》14 集正片后面还跟着 14 条预告，而它们的 `long_title` 里根本没有「预告」两个字。所以判定必须以 `badge` 为主，`long_title` 只作补充；去重时保留 `episodes` 里先出现的正片。

片名匹配也不再是「包含关键词就算命中」，`api/match.js` 按 0~100 打分：完全同名 100，只差季号/版本 95，多出后缀按长度递减，再对「预告 / 花絮 / 舞台剧 / 采访 / 剧场版」和季号不符做扣分。低于 60 分不自动加载（《狂飙》只会命中「弹速狂飙」51 分，宁可不配也不乱配），低于 25 分直接不进候选列表。文件名带季号时优先选同季，找不到同季就留空并提示手动选，绝不把第一季的弹幕套到第四季上。

## 四、从源码编译（国内镜像）

环境：**Node.js 22+**（自带 npm）。`pc/` 目录下的 `.npmrc` 已把所有下载源指向国内镜像：

```ini
registry=https://registry.npmmirror.com
electron_mirror=https://npmmirror.com/mirrors/electron/
electron_builder_binaries_mirror=https://npmmirror.com/mirrors/electron-builder-binaries/
```

```bash
cd pc                # 以下命令都在 pc/ 目录下执行
npm install          # Electron 本体也从 npmmirror 下载，不需要梯子
npm run dev          # 开发模式（Vite HMR + Electron）
npm run dist         # 打包出安装版 + 便携版，产物在 release/
```

如果 Electron 二进制下载失败，可手动指定镜像后重试：

```bash
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm install
```

## 五、已知限制

1. **HEVC / 杜比视界**：Chromium 的 HEVC 支持依赖系统解码器，部分片源会报「无法解码」。网盘播放在设置里切到「转码流播」通常就能播。
2. **海外资源站**：谷哥搜 / KK搜 / Panpansou / Pansou.de 托管在境外，国内直连可能超时；程序会跟随系统代理，开了加速器后即可用。觅盘在国内，始终可用。
3. **夸克接口**：走的是网页端非公开接口（与 OpenList 等第三方客户端一致），官方调整参数或风控策略时可能需要同步更新 `electron/api/quark.js`。
4. **播放列表**：网盘目录内连续播放已支持（当前目录即播放队列），跨目录连播暂未实现；本地与网盘各自成队，不会互相串。
5. **登录态**：Cookie 只保存在本机 `%APPDATA%\GlassPlayer\glassplayer.json`，不会上传；失效时到网盘页重新扫码即可。
